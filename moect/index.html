快速上手

三步完成微信记录归档

01

安装并连接微信

安装 Moect，登录电脑微信，点击「连接微信」。也可以先打开软件内的演示数据。

02

选择导出内容

选择会话、朋友圈或表情包，再按需要设置格式、时间范围与压缩选项。

03

查看归档文件

在任务中打开导出文件。完整保留 HTML 与资源目录，就能继续离线翻阅。

GOOD TO KNOW

常见问题

还有其他问题
支持哪些系统与微信版本？

适用于 Windows 10 1809 或更新版本、Windows 11 x64，需要 Microsoft Edge WebView2。面向 Windows 微信 4.x，微信更新可能影响适配，具体支持情况请查看项目说明。

图片、视频和朋友圈都能保存吗？

取决于本地缓存、可用凭据与原始文件。朋友圈需要先在微信中手动浏览目标内容，再回到 Moect 刷新快照。没有取得的附件会显示具体状态，已失效的远端内容可能无法恢复。

导出的 HTML 如何离线阅读？

完整保留导出文件夹中的 HTML、消息分片与资源目录，再用浏览器打开 HTML 即可。可以搜索记录、按时间筛选、展开合并转发，也可以打印或另存为 PDF。

安装版和便携版有什么区别？

安装版提供安装位置、桌面快捷方式等选项，并按需准备 WebView2。便携版需要完整解压后运行 Moect.exe，保留同级 _internal 目录，并使用系统已安装的 WebView2。
